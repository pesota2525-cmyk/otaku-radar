# OTAKU RADAR V3

V2から大きく変更し、Google Newsだけに頼らず、公式/ショップページを直接巡回する仕組みを追加しました。

## V3の主な変更

- ゲーマーズ「イベント・フェア / POP UP」一覧を直接巡回
- げっちゅ屋のPCゲーム / 特典ページを直接巡回
- アキバ☆ソフマップのPCゲーム特典商品を直接巡回
- メロンブックスのPCゲーム / 漫画特典 / 同人情報を直接巡回
- あみあみ / トレーダーもベストエフォートで直接巡回
- 女性撮影会は水着 / コスプレ / グラビア / 女性モデル系に寄せる
- 未成年と明記された撮影会は除外
- Pigoo / 全東京写真連盟 / BerryJuice / FESTASOLE / Viewit / 女性撮影会アンテナを追加
- Google Newsの巨大ロゴ画像は表示しない
- 画像がない記事はコンパクトな文字カードに変更
- 「公式直」バッジを追加
- 18+ 情報にはバッジを表示
- 今日 / 3日 / 7日 / 14日フィルター
- URLベースの安定IDに変更（お気に入りが更新のたびにズレにくい）

## 重要
ショップ側がbotアクセスをブロックした場合、その情報源だけ取得できないことがあります。
その場合でも他の直接取得・Google News補助は動き続けます。

「可愛い女性」の自動判定は行いません。
顔の魅力度を勝手に評価せず、ページ本文に
「女性モデル / 水着 / コスプレ / グラビア / 女優 / アイドル / 個撮」
等がある撮影会へ絞っています。

## 既にV2をGitHubへ公開している場合

`.github/workflows/update.yml` はそのままでOKです。

GitHubで以下を上書きしてください。

- `config/sources.json`
- `scripts/fetch_feeds.py`
- `index.html`
- `app.js`
- `style.css`

`requirements.txt` はV2と同じですが、一緒に上書きしても問題ありません。

上書き後:
Actions → Update OTAKU RADAR → Run workflow

でV3データを生成してください。
