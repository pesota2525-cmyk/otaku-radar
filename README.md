# OTAKU RADAR

画像中心で「見たら欲しくなる / 行きたくなる」新着を流し見る、自分専用レーダーです。

## 入っているカテゴリ
- アニメグッズ
- フィギュア
- 一番くじ・プライズ
- コラボ / POP UP
- コスプレイベント（関東寄り）
- 撮影会・モデル撮影会（関東寄り）
- 注目商品レーダー（抽選・完売・品薄・再販・限定など）
- PC美少女ゲーム / エロゲの予約・店舗特典
- 漫画・コミックの購入 / 店舗特典
- 同人誌の新刊・予約・限定特典
- ゲーマーズのPOP UP・フェア・イベント・限定情報

## 完全無料の構成
- GitHub Pages: サイト公開
- GitHub Actions: 1日2回の自動更新
- Google News RSS: 新着候補の収集
- Python: 重複除去・カテゴリ化・OG画像のベストエフォート取得

> 注意: 商品画像は配信元サイトがOG画像を提供し、外部取得を許可している場合だけ表示されます。
> 「注目商品」は転売利益を保証するものではなく、公開情報中の「抽選/品薄/再販/限定」等を拾う発見用カテゴリです。

## あなたがやること（約5〜10分）

### 1. GitHubで新しいリポジトリを作る
1. GitHubにログイン
2. `New repository`
3. Repository name: `otaku-radar`
4. **Public** を選ぶ
5. `Create repository`

### 2. このZIPを展開して、中身を全部アップロード
GitHubのリポジトリ画面で:
`Add file` → `Upload files` → ZIPの**中身**を全部ドラッグ → `Commit changes`

`.github` フォルダも必要なので、フォルダ構成を崩さずアップしてください。

### 3. GitHub PagesをON
`Settings` → `Pages` → `Build and deployment` → `Source` を **GitHub Actions** にする。

### 4. 最初の更新を手動実行
`Actions` → `Update OTAKU RADAR` → `Run workflow`

数分後、`Settings` → `Pages` に公開URLが出ます。

## 更新時間
- 毎日 07:15 JST
- 毎日 19:15 JST

変更したい場合は `.github/workflows/update.yml` の `cron` を変更します（cronはUTC）。

## 情報源を増やす
`config/sources.json` の `sources` にGoogle News検索クエリを追加します。

例:
```json
{
  "name": "カード新商品",
  "category": "trend",
  "type": "google_news",
  "query": "トレーディングカード (抽選 OR 再販 OR 予約開始)"
}
```

## 次に強化できるもの
- 特定ショップの公式RSS/API
- イベント公式ページの専用取得
- 価格表示
- 開催日カレンダー
- LINE/Discord通知
- 「興味なし」を学習して並び順を変える機能

無断スクレイピング前提にはしていません。個別サイトを直接取得する機能を追加する場合は、そのサイトの利用規約・robots/API仕様を確認してから追加してください。


## 追加カテゴリについて
### PCゲーム特典
「美少女ゲーム」「PCゲーム」「予約特典」「店舗特典」「描き下ろし」等の公開情報を拾います。

### 漫画特典
単行本・コミックのイラストカード、描き下ろし、店舗別購入特典などを拾います。

### 同人誌
新刊・予約・限定・ショップ特典などを拾います。

### ゲーマーズ
ゲーマーズのPOP UP、フェア、オンリーショップ、先行販売、限定特典などを拾います。

検索ベースなので、記事化されないショップ内限定情報は取りこぼす場合があります。
